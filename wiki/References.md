# References and thanks

> InoQuill v1.0.0 by TabGrinder

The projects, people, and documentation that helped shape InoQuill.

InoQuill grew out of an appreciation for Spacehuhn’s Duckify, Duckuino, SAPSAN Terminal, and Hak5’s documentation. Their work inspired this project and helped make it possible. Thank you to the creators and contributors who make these tools and resources available to everyone.

## What these references helped with

Arduino and DigiKeyboard sources help explain key codes and keyboard reports. Hak5 documentation provides the reference for DuckyScript commands. OWASP and W3C guidance inform security and accessibility decisions, while GitHub documentation helps with project maintenance. InoQuill is independently maintained by TabGrinder; these credits do not imply affiliation or endorsement.
